# CoC7th 飞书跑团 · 5 分钟上手

> 所有跑团操作在 **飞书** 里完成。电脑只需要保持 DeepSeek Harness 在后台运行，**不需要**打开任何桌面界面。

---

## 第 0 步：前提

- 你的电脑已经按 `DEPLOY.md` 装好 DeepSeek Harness、dsh-lark-bot、coc7th-keeper 三件套
- 你的飞书 App 已登录
- 你和 1-2 位朋友都有飞书账号

---

## 第 1 步：开启守密人后台（在你的电脑上）

打开 PowerShell：

```powershell
dsh --profile dsh-lark
```

首次会打印一个飞书登录二维码。**用手机飞书 App 扫一扫**，按提示授权。

绑定成功后，DSH 进程**保持运行**——这是你的"守密人控制台"，整个跑团期间都不能关。

> 💡 想让守密人后台在开机时自动启动？dsh-lark-bot 支持后台常驻，详见 dsh-lark-bot README。

---

## 第 2 步：建一个跑团群

在飞书 App 里：

1. **消息** → **发起群聊** → 选你的朋友（建议 1-2 人）→ 建群
2. 给群起一个有意义的名字，比如「**周末跑团：惊魂**」
3. 进入群 → **群设置** → **群机器人** → **添加机器人** → 选你的 dsh-lark-bot
4. （可选但推荐）群管理 → 设为「**免 @ 触发**」

**一个飞书群 = 一个跑团房间**。多人群就是多场跑团，互不干扰。

---

## 第 3 步：守密人开团（在群里发）

作为守密人（KP），你在群里发：

```
/coc init demo --module the-haunting --kp 守密人的飞书名
```

守密 agent 加载 coc7th-keeper skill → 调脚本 → 飞书卡片回复：

> 🏠 房间 `demo` 已创建
> 📜 剧本：惊魂
> 👤 守密人：xxx
> ⏰ ...

> 💡 **群不响应怎么办**？如果群里发指令后没反应，在指令前 @ 一下 bot：
> ```
> @coc-bot /coc init demo --module the-haunting --kp 守密人
> ```
> 部分 dsh-lark-bot 配置需要 @ 才触发。

---

## 第 4 步：玩家加入房间

每位玩家在群里发：

```
/coc join
/coc use-pregen theron-quist
```

agent 会自动：
- 把玩家的飞书名记为角色名
- 把预制角色（心理学家西伦·奎斯特）的属性复制到玩家房间
- 在飞书卡片里显示角色卡

**没有预制角色也行**：

```
/coc join
/coc build
```

`/coc build` 用标准规则（5d6 取大3 + 教育 2d6+6）现场生成一个随机角色。

---

## 第 5 步：守密人开场

守密人发：

```
/coc scene 大堂
```

守密 agent 加载模组的开场白，描述场景：

> _秋日午后，雨雾笼罩着波士顿的坎布里奇区。你撑着黑伞，拐进 Bouverie 街 18 号的维多利亚式公寓楼。_
>
> _楼里散发着陈年木头和发霉的混合味。门口，一位灰白头发的瘦削男人正在擦栏杆——他抬头看了你一眼。_
>
> _「你是来找伯纳德先生的？他在三楼。三楼 A 室。」_

然后等待玩家行动。

---

## 第 6 步：玩家行动与检定

每位玩家在群里自由决定何时检定：

```
/coc check "Spot Hidden" --why 走廊尽头暗门
/coc roll 1d100 --why 听地下室动静
/coc san 3 --why 看到阁楼的死鸟
/coc luck
```

守密 agent 调对应脚本，把 JSON 输出渲染成飞书卡片：

> 🎲 侦查（Spot Hidden）检定
> 玩家：爱丽丝 ｜ 技能值：60
> 掷骰：29
> **✓ 困难成功**

> 💡 **省略技能值**：如果你不确定自己的某项技能值，写 `/coc check "Spot Hidden"`，agent 会自动从你的角色卡里读。

---

## 第 7 步：守密人调度

守密人发：

```
/coc reveal C-02      # 解锁一条线索给玩家（只显示线索本身）
/coc npc calvert      # 召唤 NPC 速查
/coc handout 旧剪报.png # 展示剧本附件
/coc kp-note 记下一条仅守密人可见的备忘   # 内容永不外发，群聊只回「已记录」
```

> 🔒 **`/coc kp-note` 只是记录**：内容写进本地 `kp-notes.md`，群聊只回复「已记录」，**绝不回显笔记内容**（隐私铁律，见 SKILL.md §2）。

---

## 第 8 步：审计与存档

任何人发：

```
/coc audit                # 最近 20 条投骰
/coc audit --last 50      # 最近 50 条
/coc save                 # 保存房间快照
/coc status               # 查看所有人 HP / 理智
```

---

## 第 9 步：战斗（地下室高潮）

玩家（攻击）：

```
/coc attack 50 25 1d6+1 +0 --why 拳击鬼魂
```

守密人（鬼魂 Dodge / 反击）：

```
/coc dodge joseph_ghost
```

agent 调用战斗脚本，自动扣减玩家 HP，并把结果记入投骰审计记录（发 `/coc audit` 可查）。

---

## 第 10 步：守密人十条（agent 必守）

| # | 守则 |
|---|---|
| 1 | 不替玩家说话 |
| 2 | 不替玩家决定检定时机 |
| 3 | 失败要有戏剧后果 |
| 4 | 理智损失 ≥ 5 时暂停问询"是否进入实时疯狂" |
| 5 | HP ≤ 0 自动查重伤表 |
| 6 | 现实敏感题材（自杀、性侵、儿童伤害）必须先警告并让玩家选择 |
| 7 | 规则不熟查 references/ |
| 8 | 守密人笔记绝不外泄（仅守密人内部可见） |
| 9 | 投骰必须走脚本，绝不口算 |
| 10 | 风格随场景切换（神秘冷峻 / 紧张紧凑 / 慢热会话） |

## 常见问题

**Q：群里没人发指令时，bot 会说话吗？**
不会。dsh-lark-bot 默认空闲，Agent 不主动发起回合。

**Q：可以多人多房间吗？**
可以。建多个飞书群，每个群 = 一个房间。不同房间之间数据完全隔离。

**Q：怎么暂停一个正在进行的回合？**
在群里发 `/stop`（dsh-lark-bot 内置）。

**Q：玩家想看剧本日志怎么办？**
打开 DSH 的 Web 界面查看剧本日志；也可以请守密人在群里发 `/coc status` 回看当前状态。日志里的路径只会以相对形式出现，不会暴露电脑上的真实路径。

**Q：手机能用吗？**
能。飞书群消息直达；bot 用 WebSocket 长连接回你的电脑，无需固定 IP。

**Q：投骰公平吗？**
完全公平。每次掷骰用加密安全随机数（Python `secrets` 模块），结果记入仅追加、不可篡改的投骰审计记录，任何人可用 `/coc audit` 审计。

**Q：跑到一半电脑关了会丢吗？**
跑团期间，每 30-60 分钟发一次 `/coc save`，生成的快照可永久保存。下次发 `/coc load <路径>` 恢复。

**Q：群里会看到守密人小抄吗？**
不会。守密人笔记、内部提示、（PL 不可见）标注等 KP 专属内容被隐私铁律列为最高禁止项，任何情况下都不会发到跑团群。

| `/coc help` | 全部 | 列出所有指令 |

| `/coc san <损失量>` | 全部 | 理智损失检定 |
| `/coc say <台词>` | 玩家 | 角色发言 |

| `/coc scene / npc / reveal / handout / kp-note` | 守密人 | 守密人工具 |
