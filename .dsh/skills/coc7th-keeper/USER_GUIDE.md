## 什么是 CoC7th 跑团？

《克苏鲁的呼唤》（Call of Cthulhu，简称 CoC）是混沌社（Chaosium）出品的经典桌面角色扮演游戏，第七版（7th Edition，简称 7th）是目前最流行的版本。

在这个 skill 里，**AI 扮演守密人（Keeper，KP）**，**你扮演调查员（Player Character，PL）**。你们在飞书群里互动，AI 用规则脚本判定你的行动是否成功，并讲出后续的恐怖剧情。

游戏的核心体验是：**调查、推理、面对未知、理智边缘**。不是打怪升级，而是发现世界的真相，并因此付出代价。

## 一、你的第一个跑团日

### 1.1 加入飞书跑团群

守密人会邀请你进入一个飞书群。群里有一个机器人，它的头像通常带"AI"或"bot"标识。

**这个机器人就是守密人 AI**——你跟它说话。

### 1.1.5 先看一眼可玩的模组

进群后第一件事，先发：

```
/coc modules
```

机器人会列出所有可玩模组（编号 + 中文名）。挑好后发 `/coc init <房间号> --module <模组id> --kp 你的飞书名` 开局。房间号随便起（默认 `demo`）。

### 1.2 加入房间

在群里发：

```
/coc join
```

机器人会自动用你的飞书名作为你的角色名。

### 1.3 选择角色（两种方式）

**方式 A：用预制角色**（推荐第一次玩）

```
/coc use-pregen theron-quist
```

会用一张预制角色卡（心理学家西伦·奎斯特）。你也可以选 `delphine-mcquire`（调查员德尔菲娜）。

**方式 B：随机生成**

```
/coc build
```

用标准 CoC7th 规则现场生成：
- 力量、体质、体型、敏捷、魅力、智力、意志、教育：5d6 取最高的 3 个相加 × 5
- 幸运：5d6 取最高的 3 个 × 5
- 派生值：体力 = ⌈(体质 + 体型) / 10⌉；魔法 = ⌈意志 / 5⌉；理智 = 意志 × 5

### 1.4 查看自己的角色卡

```
/coc stat
```

机器人会发送一张卡片，显示你的：

| 项目 | 说明 |
|---|---|
| 力量（STR） | 影响近战伤害 |
| 体质（CON） | 影响体力上限 |
| 体型（SIZ） | 影响体力、伤害加值 |
| 敏捷（DEX） | 影响先攻、闪避 |
| 魅力（APP） | 影响社交 |
| 智力（INT） | 影响知识类技能 |
| 意志（POW） | 影响魔法、幸运上限 |
| 教育（EDU） | 影响知识类技能 |
| 幸运（LUK） | 每日幸运检定 |
| 体力（HP） | 跌至 0 触发重伤 |
| 理智（SAN） | 跌至 0 永久疯狂 |
| 伤害加值（DB） | 由力量 + 体型决定 |
| 闪避（Dodge） | 默认 30 |

## 二、跑团怎么玩？

### 2.1 守密人讲场景

守密人会在群里发一段中文叙事，描述你看到、听到、闻到的内容。**然后等你的指令**。

例如：

> _雨雾笼罩着波士顿的坎布里奇区。你撑着黑伞，拐进 Bouverie 街 18 号的维多利亚式公寓楼。_
>
> _楼里散发着陈年木头和发霉的混合味。门口，一位灰白头发的瘦削男人正在擦栏杆——他抬头看了你一眼。_
>
> _「你是来找伯纳德先生的？他在三楼。」_

### 2.2 你行动

作为玩家，你可以：

- **做动作**（直接打字描述你在做什么）：
  > 我把伞收起来，跟他打招呼。
- **说话**（用 `/coc say` 让守密人把它记入日志）：
  > /coc say 您好，我是伯纳德的老朋友，请问他在哪个房间？
- **检定**（用 `/coc check`）：
  > /coc check "Spot Hidden" --why 我想观察这位管理员的表情
- **看资料**（用 `/coc roll`）：
  > /coc roll 1d100 --why 我偷听门后动静

### 2.3 守密人讲结果

守密人会根据检定结果决定你看到什么、听到什么、记得什么。可能是：

- **大成功（掷出 1）**：你看到了远超常人的细节
- **极难成功**：你捕捉到关键线索
- **困难成功**：你发现一些有用信息
- **成功**：你基本做到了
- **失败**：你没做到，可能还有负面后果
- **大失败（掷出 100）**：出了大问题

## 三、完整的指令清单（玩家视角）

### 3.1 角色相关

| 指令 | 说明 |
|---|---|
| `/coc join` | 加入房间（首次自动用飞书名作为角色名） |
| `/coc leave` | 离开房间 |
| `/coc build` | 用标准规则随机生成角色 |
| `/coc use-pregen theron-quist` | 选用预制角色（心理学家） |
| `/coc use-pregen delphine-mcquire` | 选用预制角色（调查员） |
| `/coc stat` | 查看自己的角色卡 |

### 3.2 检定与投骰

| 指令 | 说明 |
|---|---|
| `/coc roll 1d100 --why ...` | 任意投骰 |
| `/coc roll 2d6+3 --why ...` | 多面骰 + 修正 |
| `/coc roll d20 --why ...` | 简写 1d20 |
| `/coc check "Spot Hidden" --why ...` | 侦查检定 |
| `/coc check "Listen" --why ...` | 倾听检定 |
| `/coc check "Fighting(Brawl)" --why ...` | 拳击检定 |
| `/coc check "Firearms(Handgun)" --why ...` | 手枪检定 |
| `/coc check "Dodge"` | 闪避检定 |
| `/coc check "Psychology"` | 心理学检定 |
| `/coc luck` | 幸运检定（每日首次） |
| `/coc san 3 --why ...` | 理智损失检定（损失 3 点） |

> 💡 **不知道某项技能的当前值？** 直接 `/coc check "技能名"`，机器人会自动从你的角色卡读。

### 3.3 战斗

```
/coc attack <你的攻击技能> <对方闪避> <伤害骰> <伤害加值> --target <目标名>

例如：
/coc attack 50 25 1d6+1 +0 --target joseph_ghost
```

- 第1 个数字：你的攻击技能值（如拳击 50）
- 第2 个数字：对方闪避（Dodge）
- 第3 个：武器伤害（如 `1d6+1`）
- 第4 个：伤害加值（DB，如 `+1d4`、`-1`、`0`）

### 3.4 表达与状态

| 指令 | 说明 |
|---|---|
| `/coc say <台词>` | 你（角色）说一句台词，记入剧本日志 |
| `/coc status` | 查看所有人的体力 / 理智 |
| `/coc audit` | 查看最近 20 条投骰 |
| `/coc save` | 保存进度快照 |
| `/coc modules` | **查看当前所有可玩模组（编号 + 中文名 + 简介）** |
| `/coc modules <编号\|id>` | **查看某个模组的完整简介（如 `/coc modules 2`）** |

## 四、规则速查

### 4.1 判定档位

掷出 1d100，与技能值对比：

| 掷骰值 | 结果 |
|---|---|
| 1 | **大成功** |
| ≤ 技能 / 5 | **极难成功** |
| ≤ 技能 / 2 | **困难成功** |
| ≤ 技能 | **成功** |
| > 技能（且 < 100） | **失败** |
| 100 | **大失败** |

### 4.2 伤害加值（DB）

由力量 + 体型决定：

| 总和 | DB |
|---|---|
| ≤ 64 | -2 |
| 65-84 | -1 |
| 85-124 | 0 |
| 125-164 | +1d4 |
| 165-204 | +1d6 |
| ≥ 205 | +2d6 |

### 4.3 理智损失骰

| 损失量 | 骰面 |
|---|---|
| 0 | 1d10 |
| 1 | 1d3 |
| 2-4 | 1d4 |
| ≥ 5 | 1d6（可能触发实时疯狂） |

### 4.4 受伤与死亡

体力 ≤ 0 时掷重伤表：

| 骰值 | 后果 |
|---|---|
| 1-3 | 失血过多：每轮 1d3 伤害直至 Medicine 止血 |
| 4-5 | 昏迷 |
| 6-7 | 重伤：体力上限永久 -1d10 |
| 8 | 体力上限减半 |
| 9-10 | 濒死：下一轮未救治即死亡 |

### 4.5 战斗轮

1. 掷先攻（敏捷 + 1d10）→ 高者先行动
2. 攻击（投攻击技能 vs 对方闪避）
3. 成功则掷武器伤害 + DB
4. 失败则被对方反击 / 失去行动机会

## 五、跑团的"礼仪"

### 5.1 你应该做的

- ✅ **自己决定何时检定**。不要问守密人"我该投哪个技能？"
- ✅ **主动说台词**。即使守密人不问你，也要让角色说话。
- ✅ **接受失败**。CoC 的魅力在于失败，不要作弊刷分。
- ✅ **关注队友**。读一读他们在做什么，可以配合。

### 5.2 你不应该做的

- ❌ **不要替守密人讲场景**。等守密人描述，不要猜剧情走向。
- ❌ **不要刷屏**。一条消息说完再说下一条。
- ❌ **不要带 OOC（玩家情绪）进剧情**。CoC 是虚构的，不是现实。
- ❌ **不要触发现实敏感题材**。如果你不想扮演某场景，可以跟守密人（机器人）说 `/coc say 我选择跳过`。

## 六、跑团怎么结束？

- **剧情自然结束**：守密人会在 NPC 真相大白或玩家离开时给出收尾卡片
- **中途保存**：`/coc save` 生成快照（`.json` 文件），下次用 `/coc load <路径>` 恢复
- **退出房间**：`/coc leave`，你的角色卡保留在房间里，下次可重新加入

## 七、常见问题

**Q：机器人没响应怎么办？**
- 在指令前 @ bot：`@coc-bot /coc ...`
- 检查你是否在跑团群（不是私聊）
- 让守密人检查 DSH 是否还在运行

**Q：掷骰结果我不服，可以重投吗？**
- 不可以。每次投骰写入审计日志，仅追加不可篡改
- 但你可以做"追加检定"：失败后再投一次（部分规则允许，需守密人确认）

**Q：我能在手机飞书玩吗？**
- 可以。手机版飞书功能完整

**Q：好友不在场能跑团吗？**
- 可以。CoC7th 设计就支持单人玩（Pl 为 1 也成立）
- 本 skill 模组《惊魂》已精简为 1 KP + 1-2 PL

**Q：可以多个跑团群同时跑吗？**
- 可以。每个群 = 一个独立房间
- 飞书机器人在多个群分别担任守密人，互不干扰

**Q：跑团数据存在哪里？安全吗？**
- 存在守密人的电脑本地（默认相对目录 `coc-session/`）
- 仅守密人可见；玩家不可直接访问
- 投骰审计：仅追加、不可篡改，玩家可用 `/coc audit` 查看

**Q：守密人 AI 错了规则怎么办？**
- 提醒它："这条规则应该是 XXX"
- 或请守密人（真人）校对

## 八、隐私与数据

> 机器人严格遵守「频道隐私铁律」（见 `SKILL.md` §2）：跑团群聊里**永远不会**出现守密人才看得见的东西。

- **群聊永远不会出现**：守密人笔记（`kp-notes.md`）、内部提示 / 守密人旁注、（PL 不可见）标注、未揭示的线索与真相、隐藏 NPC / 怪物数值、机器绝对路径（`D:\...` / `C:\Users\...`）。
- **检定失败只描述检定者没能看出更多**：例如「你仔细检查，没能从中看出更多端倪」。这不是机器人在敷衍你，而是守密人的职业操守——失败的真相只能由剧情慢慢揭开，**不会**出现「其实你没发现 X，线索在 Y 处」这类剧透，也**不会**断言「没有异常」（断言"没有"同样是剧透）。
- **`/coc kp-note`（守密人笔记）**：只会写入守密人电脑本地的 `kp-notes.md`，群聊里最多只回复「已记录」，**从不回显内容**。
- **路径显示**：涉及保存 / 读档 / 数据位置时，机器人只显示相对路径（如 `coc-session/demo/players/alice.json`），**从不显示**电脑上的完整绝对路径。
- **数据存在哪里？** 全部存在守密人电脑本地 `coc-session/`；投骰审计 `dice.log`（仅追加）随时可查。
- **私聊里也一样安全吗？** 即使私聊，机器人也只在**确认对方是守密人本人且明确要求**时，才展示 KP 数据概要；私聊里看到的 KP 数据不会被带到任何群聊。

**Q：群里会看到守密人的"小抄"或内部提示吗？**
- 不会。守密人笔记、内部提示、（PL 不可见）标注等 KP 专属内容被隐私铁律列为最高禁止项，任何情况下都不会发到跑团群。

## 九、给守密人（KP）的补充

> 你是真人守密人还是 AI 守密人？这份文档假设你是 **AI 守密人**。但如果你也是真人玩家在使用本 skill，请遵守守密人十条（见 SKILL.md）。

**守密人的工作**：

1. **开团前**：发 `/coc modules` 让玩家选 → `/coc init <房间号> --module <模组id> --kp 你的飞书名`
2. **每回合**：观察玩家指令 → 决定检定 → 跑脚本 → 渲染叙事 → 写日志
3. **遇到敏感题材**：先警告再继续；让玩家选 skip
4. **剧终时**：发 `/coc save` 保留快照
5. **守密人内部笔记**：发 `/coc kp-note ...` 给自己看

**你不需要做的事**：

- 不用记得所有规则——规则速查表已准备好
- 不用替玩家检定——等他们自己发指令
- 不用维护任何数据库——脚本自动写 JSON
