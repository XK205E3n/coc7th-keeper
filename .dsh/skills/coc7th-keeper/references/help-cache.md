📜 **CoC7th 守密人指令清单**

**通用**
- `/coc help` — 列出所有指令（本指令）
- `/coc guide / 使用说明 / tutorial / 教程` — 完整使用说明书（新人必读）
- `/coc quickstart` — 5 分钟快速上手
- `/coc status` — 查看房间与全部玩家状态
- `/coc audit [--last N]` — 最近 N 条投骰审计（掷骰与理由玩家可见）
- `/coc save` — 保存房间快照（群聊只回显相对路径）
- `/coc load <快照路径>` — 从快照恢复（路径用相对形式）
- `/coc pwd` — 显示当前房间数据目录（群聊只显示相对路径）
- **`/coc modules`** — 查看所有可玩模组（共 2 个，编号 + 中文名 + 简介）
- **`/coc modules <编号|id>`** — 查看某个模组的完整简介

**玩家专用**
- `/coc join` — 加入房间
- `/coc leave` — 离开房间
- `/coc build [--age N]` — 随机生成角色（5d6 取大3）
- `/coc use-pregen <名>` — 选用预制角色（theron-quist / delphine-mcquire）
- `/coc stat / sheet` — 查看自己的角色卡
- `/coc roll <表达式>` — 任意投骰（1d100 / 2d6+3 / d20）
- `/coc check <技能> [值] [--why ...]` — 技能检定
- `/coc luck` — 幸运检定
- `/coc attack <攻击技能> <对方闪避> <伤害骰> <伤害加值>` — 攻击
- `/coc dodge <对方攻击>` — 闪避
- `/coc san <损失量> [原因]` — 理智损失检定
- `/coc say <台词>` — 角色发言，记入剧本日志
