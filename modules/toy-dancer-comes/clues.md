## 起点

- [ ] **C-01** 半露木构架式建筑知识：英格兰北方典型建筑，黑木骨架 + 浅填充墙 + 鱼鳞状叠瓦。可通过知识检定或《英国建筑史》了解。

## 一楼

- [ ] **C-02** 展示柜内零散无落灰位置（侦查 35）—— 机关木偶原本摆放在此处，现已被搬走伪装修为 NPC。
- [ ] **C-03** 《英国建筑史》（松本清之介著）：定义半露木构架式建筑；图书馆使用可查「人偶公馆 = 1900 年曼彻斯特，谢尔顿·夏普建造，同年病逝」。
- [ ] **C-04** 日文交易合同（床头柜抽屉）：人偶公馆交易证明，对象为松本幸嗣。

## 二楼

- [ ] **C-05** 二楼卧室与书房的水泥天花板（侦查 35）：外观仿木，实际是水泥制成，无法破坏。半露木构架式本不应存在天花板。
- [ ] **C-06** 《世界奇妙玩具物语》（图书馆使用）：私印书籍，灰黑皮革封面黏腻手感。翻阅后理智检定（0/1）。**关键：讲述玩具修理者故事**。
- [ ] **C-07** 书架后铁门（侦查 35）：地面摩擦痕迹 → 书架暗藏滑轮 → 铁门紧嵌墙面，特制门锁，无钥匙无法打开。

## 园区 NPC

  - 真多鱼仓买：乱定价 / 冷饮自然融化
  - 剪之境造型：理发糟糕 / 两人不同步

## 终极真相（**仅守密人可见**）

> 谢尔顿·夏普 1900 年将自身肉体献祭给撒旦，与古宅同化。每 21 年 7 月 17 日实施肉体更换仪式，失踪者成为容器。1995 年古宅随沈青鸣迁至松寒市。2011 年沈珂成察觉真相并尝试召唤玩具修理者，被谢尔顿提前献祭。2012 年仪式期限将至，谢尔顿伪装成「沈珂成」邀请调查员入住。调查员在与玩具修理者建立联系后，可以借助破坏微缩模型 + 童年玩具击溃谢尔顿灵魂，进入结局 A。

1. **暖场** → 抵达秋林苑 / 与「沈珂成」交流（场景 1）
2. **一楼探索** → 大厅展示柜 / 卧室《英国建筑史》/ 日文合同（场景 2）
3. **二楼探索** → 卧室书房天花板 / 书架 / 《世界奇妙玩具物语》/ 铁门（场景 3）
4. **园区探索** → NPC 异常（场景 4）
5. **众人目送** → 鬼打墙 → 玩具屋（场景 5）
6. **玩具屋** → 修理猫 → 密码盒 → 银钥 + 小飞象（场景 6）
7. **阁楼** → 《英国幽灵住宅》/ 沈珂成笔记 / 微缩模型（场景 7）
8. **快逃** → 23:50 → 血字「快逃」/ 木偶围堵（场景 8）
9. **突破** → 小飞象 / 4 次敏捷对抗（场景 8）
10. **回头客** → 接受改造 / 选童年玩具（场景 9）
11. **最终战** → 与谢尔顿决战 → 结局（场景 10）

守密人可在玩家长时间停滞时主动透露以下提示：
- 「天气黏腻湿热」 → 强化东北不该有的诡异
- 「NPC 偶尔敲太阳穴」 → 提前铺垫后期巡警「惊喜」
- 「众人齐刷刷盯人」 → 引导玩家发现 NPC 非人类
- 「鬼打墙后出现玩具屋」 → 接受邀约或继续挣扎
- 「《魔女的灭门诅咒》提到玩具修理者」 → 暗示祂的真实性
- 「沈珂成笔记 1991 年松本幸嗣失踪」 → 暗示「沈珂成」≠ 真沈珂成
