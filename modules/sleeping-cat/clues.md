## 终极真相（**仅守密人可见**）

> 静眠山是现实与幻梦境的边界。数百年前，来自幻梦境的高贵之猫 Shiro 被樵夫的温柔打动，化为石像守护着这里。粗心的游客**镰仓佐羽**碰动了石像，让两只**冷蛛**降下。调查员需要在群猫的指引下找回沉眠之猫石像，归还台座，切断现实与幻梦境的连接。
>
> **关键测试**：白猫用日语问「这家伙有救的价值吗？」——**任何形式**表达出『温柔之心』即可通过；**失败则进入失败结局**（沉眠之猫消失 + 山再次成为危险交叉点 + 无法获得 SAN 奖励）。

## 调查路径建议

1. **暖场** → 缆车上山 + 短消息 + SNS 短文（场景 1）
2. **突转** → 缆车尸体 + 跳下缆车（场景 1）
3. **缆车站探索** → 蛛网 / 商店（场景 2-3）
4. **观景台探索** → 广场 / 结缘之钟 / 咖啡店外观 / 登山道货车（场景 3）
5. **找七味桐桐** → 通过 SNS / 咖啡店仓库（场景 4）
6. **引开冷蛛** → 结缘之钟 / 潜行（场景 5）
7. **登山道** → 看板 / 群猫 / 白猫的询问（场景 6）
8. **冷蛛袭来** → 分散注意力 / 敏捷 / 安抚（场景 7）
9. **终末** → 石像归位 → 切断 → 通关奖励（场景 8）

守密人可在玩家长时间停滞时主动透露以下提示：
- 「你试了但它纹风不动」→ 拒绝不合理行动
- 「结缘之钟声音大得惊人」→ 引导引开冷蛛
- 「群猫突然一齐看向调查员」→ 强化紧张感
- 「白猫依然保持优雅」→ 暗示关键测试
- 「白（Shiro）被一位『内心温柔的男子』救助」→ 引导回答
- 「石像发出不耐烦的猫叫声」→ 提示『温柔之心』失败
