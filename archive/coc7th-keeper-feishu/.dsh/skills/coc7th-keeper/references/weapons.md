# CoC7th 武器、护甲速查 · 中文版

## 伤害加值（DB，Damage Bonus）

由力量（STR）+ 体型（SIZ）决定：

| 总和 | DB（中文） | 骰面数 |
|---|---|---|
| ≤ 64 | -2 | -1d4（最终 ≤ 0 视为 0） |
| 65-84 | -1 | -1 |
| 85-124 | 0 | +0 |
| 125-164 | +1d4 | +1d4 |
| 165-204 | +1d6 | +1d6 |
| ≥ 205 | +2d6 | +2d6 |

## 部位表（可选规则）

CoC7th 标准 1d10：

| 骰值 | 部位（中文） | 英文 | 备注 |
|---|---|---|---|
| 1-3 | 左腿 / 右腿 | Left/Right Leg | 移动 -MOV/2 |
| 4-6 | 腹部 / 胸部 | Abdomen / Chest | 标准伤害 |
| 7-8 | 左臂 / 右臂 | Left/Right Arm | 双手动作 -1 / 失力 |
| 9 | 头部 | Head | 伤害 ×2 |
| 10 | 头部（爆头） | Head (Critical) | 伤害 ×3；颅骨检定（命中 1d4，< STR/2 即刻晕厥） |

> 本 skill 默认**关闭部位**（保持轻量化）；KP 可用 `--location` 自选开启。
