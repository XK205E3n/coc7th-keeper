# 归档说明：coc7th-keeper 飞书版（已停用）

> 归档日期：2026-08-31 ｜ 归档原因：新项目（Web 跑团平台）采用方案 B，**完全舍弃飞书等群聊软件**，本目录整体归档、不再被调用。

## 这是什么

**coc7th-keeper 飞书版（v0.2.x）**：在飞书里跑《克苏鲁的呼唤》第七版（CoC7th）的守密人系统。

- 架构：飞书群消息 → dsh-lark-bot（WebSocket 桥接）→ DeepSeek Harness Agent → 加载 `coc7th-keeper` skill → 调用 Python 规则脚本 → 飞书卡片回传。
- 功能：完整 CoC7th 规则（build / 技能检定 / 对抗 / 幸运 / 理智 / 战斗 / 重伤）、加密安全骰子 + 追加式审计（`dice.log`）、AI 守密人（守密人十条 + 隐私铁律 + 场景自适应风格）、内置模组《惊魂》《玩具跳着舞蹈来》。
- 版本：`VERSION` 文件（v0.2.x）；变更历史见 `CHANGELOG.md`。

## 不再调用（已生效）

- `.dsh/` 已从仓库根目录移除 → DeepSeek Harness 不再扫描到 `coc7th-keeper` skill（技能目录已清空，确认卸载）。
- 新平台（Web 跑团）不依赖 dsh-lark-bot / 飞书 / DSH Desktop，运行方式见根目录 `README.md`。
- 保留在仓库根目录的项：`.git`（git 历史）、`.agent-teams`（DSH 运行时目录，非项目内容）、`docs/`（新项目文档）、`archive/`（本目录）。

## 如何恢复（如需回退）

把 `archive/coc7th-keeper-feishu/` 下全部内容移回仓库根目录，再按原 `README.md` 的部署流程操作即可。注意：原 `coc-session` 是 junction（指向 dsh-lark worktree），归档时已删除 junction 并复制实际数据，恢复后为普通目录。
