## 1 · 5 分钟上手

### 1.1 环境

| 依赖 | 最低版本 | 备注 |
|------|----------|------|
| Python | 3.12+（推荐 3.14） | 后端运行 + pytest |
| Node.js | 22 LTS（推荐 22.22.2） | 前端构建 |
| OS | Windows / macOS / Linux | 一键脚本是 Windows；其它平台看 §1.4 手动 |
| 内存 | 2 GB+ | LLM 走外部 API，本地不占显存 |

### 1.2 Windows 一键启动（推荐）

```powershell
cd 'D:\path\to\跑团'
.\start-web.ps1            # 首次会自动 npm install + npm run build
```

启动后：
- **生产模式**：浏览器打开 <http://localhost:18000>
- **开发模式**（前后端分离、热重载、便于改前端）：`.\start-web.ps1 -Dev` → 浏览器打开 <http://localhost:5173>
- **公网联机（一键穿透）**：`.\start-web.ps1 -Tunnel` 后台起后端 + 内网穿透，自动抓公网地址写回 `share_url` 后打印；`-Provider cloudflared|frp|cpolar|mock` 可切换 provider，`-Force` 跳过访问密码确认
- **仅后台起后端**：`.\start-web.ps1 -Daemon`（脚本退出，便于自托管）
- **一键关闭**：`.\stop-web.ps1`（树杀后端/穿透进程，清 pid 文件，幂等）；`.\status-web.ps1` 查状态。详见 [`docs/部署/内网穿透.md`](部署/内网穿透.md)

**Linux 服务器**（M8R6 起）：同等语义的 `./start-web.sh` / `./stop-web.sh`，参数为长选项形式 `--dev / --daemon / --tunnel [--provider …] [--force]`；后台进程经 `setsid` 独立进程组，关闭脚本按 pid 树杀。首次部署依赖安装用 `pip install -r requirements.txt`（锁定已验证版本组合）。

**纯小白路径**（M8R8 起）：根目录双击「**一键开启.bat**」→ 看窗口最下方的网址汇总块 → 玩 → 双击「**一键关闭.bat**」。逐步截图级说明见 [`docs/单人测试一键开团手册-20260904.md`](单人测试一键开团手册-20260904.md)（含密码设置、进站、故障排查）。

### 1.3 离线 vs 联机

- **无 LLM API Key**：能完整跑，所有检定/叙事走**离线兜底**（关键词推理 + 模板叙事）。质量明显下降但功能完整。
- **有 LLM API Key**：质量与真人 GM 接近。配置见 §5。

### 1.4 macOS / Linux 手动启动

```bash
cd /path/to/跑团
python3 -m venv .venv
.venv/bin/pip install fastapi 'uvicorn[standard]' openai httpx pytest
.venv/bin/python server/main.py &          # 后端 → http://localhost:18000
cd frontend && npm install && npm run build && npm run preview &  # 前端构建产物
```

> 默认端口：`server/main.py` 与 `data/config.json` 的 `server.port`（18000）。改 `config.json` 重启即可。

## 2 · 部署（生产环境）

### 2.1 三档方案对比

| 档位 | 适用场景 | 公网可访 | HTTPS | 成本 | 推荐度 |
|------|----------|----------|-------|------|--------|
| **本机单机** | 自玩 / 体验 | ❌ | ❌ | 免费 | 起步 |
| **局域网** | 同 WiFi / 办公室 | ❌（要穿透） | ❌ | 免费 | 小团体 |
| **公网隧道** | Cloudflare Tunnel / localtunnel / SakuraFrp | ✅ | ✅ | 免费 | ✅ 推荐 |
| **云服务器** | 长期稳定 + 自定义域名 | ✅ | ✅（反代） | ¥30+/月 | 专业运营 |

> 完整对比与各档操作细节看 `docs/部署/部署指南.md`（M6 已写，~150 行）。
> 反向代理 / SSE 透传要点看 `docs/部署/HTTPS反代.md`。
> 上线前核对看 `docs/部署/安全清单.md`。

### 2.2 Docker（最省心）

```bash
docker build -t coc-web .
docker run -d --name coc-web -p 18000:18000 -v coc-web-data:/app/data coc-web
```

数据持久化在 `coc-web-data` 卷（包含 `data/config.json`、`data/secrets.json`、`data/games/*.db`）。
镜像构建细节看根目录 `Dockerfile`（多阶段：node 22 构建前端 + python 3.12 slim 跑 uvicorn）。

### 2.3 systemd（Linux 云服务器）

`/etc/systemd/system/coc-web.service`：

```ini
[Unit]
Description=CoC Web Platform
After=network.target

[Service]
Type=simple
User=coc
WorkingDirectory=/opt/coc-web
ExecStart=/opt/coc-web/.venv/bin/python -m uvicorn server.main:app --host 0.0.0.0 --port 18000 --log-level warning
Restart=always
Environment=DATA_DIR=/opt/coc-web/data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now coc-web
```

## 3 · 公网联机

### 3.1 Cloudflare Tunnel（推荐 · 免费 · 零配置）

```bash
# 1) 装 cloudflared（macOS: brew install cloudflared / Linux: 官方 deb / Windows: 下载 msi）
# 2) 一行启动（会给你一个 *.trycloudflare.com 临时域名）
cloudflared tunnel --url http://localhost:18000
# 3) 把输出的 https://xxx.trycloudflare.com 发给朋友
```

零账号、零注册。**注意：每次启动域名会变**，要重新发链接。

固定域名（可选，免费）：注册 Cloudflare 账号 → `cloudflared tunnel login` → 创建命名隧道 → 绑自己的域名。

### 3.2 localtunnel（最快 · 无需安装 npx）

```bash
npx localtunnel --port 18000
# 输出 https://xxx.loca.lt 发给朋友
```

**首次访问**会要输你机器的公网 IP（防滥用），照提示填。

### 3.3 SakuraFrp（国内友好）

注册 <https://www.natfrp.com/> → 创建隧道（选 TCP 协议、本地端口 18000）→ 启动客户端 → 用分配的域名 + 端口分享。

### 3.4 邀请链接自动外网化

- **默认**：前端用浏览器当前地址生成邀请链接（你 `https://xxx.trycloudflare.com` 进站，邀请就带这个）
- **自定域名**：在 `data/config.json` 设 `"share_url": "https://your-domain.com"`，所有邀请链接走这个
- **前端覆盖**：dev mode 下可设 `VITE_SHARE_URL=https://your-domain.com npm run dev`

## 4 · 数据安全与备份

### 4.1 关键文件

| 路径 | 内容 | 备份建议 |
|------|------|----------|
| `data/config.json` | 端口、模型接口、dev_token | 必备份（含 600 权限） |
| `data/secrets.json` | API key、房间密码哈希 | 必备份（含 600 权限） |
| `data/games/*.db` | 每个房间的存档（玩家/角色/回合/消息） | 必备份（直接 cp） |
| `data/games/*.db-wal` / `.db-shm` | WAL 事务 | 复制前先停服或 checkpoint |

### 4.2 上线前安全清单（速查）

看完整版 `docs/部署/安全清单.md`。最关键的 5 条：

- [ ] `data/secrets.json` 文件权限 600（Linux：`chmod 600`）
- [ ] `data/config.json` 删掉 `"dev_token"`（不要设就是关闭）—— 要开就改成强随机
- [ ] HTTPS 已生效（公网/反代档）
- [ ] 访问密码已设（建团时设）
- [ ] `pytest -q` 全绿、`git status` 干净

## 5 · LLM 配置

### 5.1 推荐：DeepSeek（中文质量高 + 价格低）

编辑 `data/config.json`：

```json
{
  "model": {
    "provider": "openai",
    "base_url": "https://api.deepseek.com/v1",
    "model": "deepseek-chat",
    "api_key_ref": "deepseek",
    "max_tokens": 4000
  }
}
```

`data/secrets.json`：

```json
{
  "deepseek": "sk-xxxxxxxxxxxxxxxxxxxxxxxx"
}
```

### 5.2 其它兼容 OpenAI 协议的服务

| 服务 | base_url | model | 备注 |
|------|----------|-------|------|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | ✅ 推荐 |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-72B-Instruct` | 国内快 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | 海外 |
| Ollama（本地） | `http://localhost:11434/v1` | `llama3.1` | 慢但零成本 |
| OpenCode Go | `https://opencode.ai/zen/go/v1` | `mimo-v2.5` | 项目默认（已配） |

### 5.3 不配 Key（离线兜底）

完全 OK。所有检定/叙事走关键词推理 + 模板。可玩但质量低，**适合先体验流程**。

### 5.4 关键规则（你改了可能会破坏游戏）

- **隐私铁律**：`reasoning_content`（思考过程）**绝不**进玩家可见文本、消息、广播。只暴露 `message.content`。
- **服务端固定骰果**：LLM 只能"提建议需要哪个技能检定"，实际 d100 是后端掷的，玩家改了 prompt 也改不了。
- **截断处理**：长叙事被截断时，玩家侧叙事流会出现黄色 system 消息「叙事被截断，点击此处让房主调高上限」；房主面板有「一键调高到 8000/16000/32000」按钮（1000–32000 之间）。

### 5.5 调 LLM 上限（房主侧）

建团后，房主面板 → "AI 输出上限" → 改数字（1000–32000）→ 保存。其它玩家侧自动同步。

## 6 · 游玩指导

### 6.1 房主视角

1. 打开 <http://localhost:18000> → 「总览」→ 创建冒险（填冒险名、选模组、设访问密码、填玩家名）
2. 提交后跳到「游玩」页，右上「房主面板」展开：
   - **邀请链接**：复制发给朋友（含 `?key=xxx&invite=yyy`，打开即可加入）
   - **轮换邀请码**：旧码立即失效
   - **强制推进**：所有人不提交也能继续
   - **移除玩家**：被踢者 token 立即失效
   - **AI 输出上限**：1000–32000，截断时一键调高
3. 建团带模组时自动进入「惊魂」s01 场景，每轮 4 阶段：收集行动 → 裁判 → 引擎掷骰 → 叙事
4. 全员活跃提交后自动推进；有人没提交就等，无倒计时

### 6.2 玩家视角

1. 收到邀请链接 → 打开 → 浏览器自动加入（如有密码会要输入）→ 填玩家名
2. 进「角色」页建卡（3 方式）：
   - **预制角色**：选模组自带的（推荐新手）
   - **AI 草稿**：模型自动生成
   - **手动**：九属性 + 派生
   - **粘贴 JSON**：自己用 AI 生成的 `coc7-character/v1` 直接粘贴（看 `docs/角色卡模板与编辑说明.md`）
3. 进「游玩」页：
   - **看场景栏**（当前场景名/回合/阶段）
   - **看自己的角色信息栏**（HP / SAN / MP / MOV / DB / 线索数）
   - **写行动**（自然语言，如"我去检查墙上的壁炉"）→ 「提交行动」
   - **看叙事流**：每轮 AI 输出 + 骰卡 + 状态变动
   - **自由掷骰**：聊天框发 `1d100`、`3d6+2`（支持加减、多维）
   - **私密感知**：只你看到的红/橙/绿字
4. 等待全员提交 → 自动推进 → 新一轮

### 6.3 多人联机规则（房主须知）

- **邀请码**：可随时轮换，旧码立即失效
- **访问密码**：建团时设，关房间后须重设（建新团）
- **暂离 / 回归**：「房主面板」点「暂离」→ 推进时不会卡住等你；点「回归」恢复活跃
- **踢人**：被踢者 token 失效，无法再进。但已发出去的旧链接仍有效（用轮换邀请码根治）
- **多浏览器**：一个房间允许多人同时玩（2-4 人最舒服）

### 6.4 检定类型速查

| 类型 | 何时触发 | 显示 |
|------|----------|------|
| 技能检定 | 行动涉及具体技能（侦查/说服/开锁...） | 骰卡深蓝底 + 成功/失败徽章 |
| 理智检定（SAN） | 看到怪物/超自然/惨剧 | 骰卡深蓝底 + 损失理智点数 |
| 自由掷骰 | 玩家在聊天框主动 `1d100` | 聊天流中显示，不影响叙事 |
| 幸运检定 | 行动成功但有代价时，规则允许可触发 | 罕见 |

### 6.5 角色卡字段速查

详细看 `docs/角色卡模板与编辑说明.md`。最关键：

- **9 属性**：STR / CON / DEX / APP / POW / INT / SIZ / EDU / LUK（5d6×5 法则，POW 直接当百分制）
- **5 派生**：HP = (CON+SIZ)/10 / MP = POW/5 / **SAN = POW**（百分制，**禁止 ×5**）/ DB = STR+SIZ 查表 / MOV 看种族
- **46 默认技能**：分战斗/社交/学术/其他四组
- **初始理智 60%（POW=60 → SAN=60）**，下限 0（永久疯狂），归 0 触发实时疯狂
- **初始 HP = (CON+SIZ)/10**，归 0 进重伤表

## 7 · 故障排查（FAQ）

### 7.1 启动类

**Q：`start-web.ps1` 报「无法加载文件，因为在此系统上禁止运行脚本」**
A：PowerShell 默认策略 Restricted。以管理员运行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，再试。

**Q：穿透后怎么关干净？`cloudflared` 常驻后台杀不掉**
A：用 `.\stop-web.ps1` 一键关闭——按 `data/.run/*.pid` 树杀（`taskkill /PID /T /F`），并对缺失/失效 pid 按命令行兜底（只杀本项目后端 `main.py`、穿透二进制 `cloudflared/frpc/cpolar`、Vite），绝不无差别杀所有 python/node；重复执行幂等。

**Q：`npm install` 失败 / 慢**
A：设国内镜像：`npm config set registry https://registry.npmmirror.com`

**Q：8000 端口被占**
A：改 `data/config.json` 的 `server.port`，重启。

### 7.2 LLM 类

**Q：叙事明显是模板味，不像 AI**
A：没配 API key，走离线兜底。看 `data/config.json` + `data/secrets.json` 配置。

**Q：长叙事被截断、剧情断头**
A：玩家侧会显示黄色横幅 → 房主侧点「一键调高到 N」。或在房主面板手动设 8000/16000。

**Q：所有检定都成功（d100 总是小于目标值）**
A：早版本（修复前）有 SAN 双乘 bug。**当前版本（post M8）已修复**——`auto` 建卡 SAN = POW（50–90），智障判定正常波动。如还异常，看 `/api/dev/games/{key}/characters` 查每个玩家 SAN。

### 7.3 联机类

**Q：朋友打开邀请链接显示「房间不存在」**
A：
- 你建团后没把**邀请链接**（带 `?invite=yyy`）发给朋友，发的只是首页地址
- 邀请码被轮换过 → 旧链接失效，重新发

**Q：朋友加入后一直显示「加载中」**
A：浏览器 console 报 `EventSource` 连不上。90% 是**反代/隧道**没配 SSE 透传（`proxy_buffering off` + `proxy_read_timeout 3600s`）。看 `docs/部署/HTTPS反代.md`。

**Q：SSE 断连频繁**
A：免费隧道 / 限速云服务器常见。客户端会自动重连（1→2→4→8→16s 指数退避），UI 短暂重连不影响数据完整性（SSE 总线带 50 条历史回放）。

### 7.4 数据类

**Q：能不能删掉旧房间？**
A：管理员页面 → 「踢除所有玩家」+ 「关闭房间」+ 直接 `rm data/games/<key>.db`（停服后做）。

**Q：如何备份？**
A：`tar czf backup-$(date +%F).tar.gz data/`。注意 `.db-wal` / `.db-shm` 要先停服或 `sqlite3 data/games/X.db "PRAGMA wal_checkpoint(TRUNCATE)"`。

## 8 · 进阶

### 8.1 开发者监视（只读审计）

在仓库根目录执行（推荐，免手改 JSON）：

```powershell
.\.venv\Scripts\python.exe tools\config_cli.py set-dev-token 你的强随机串
.\stop-web.ps1
.\start-web.ps1 -Daemon
```

（等价做法：`data/config.json` 加 `"dev_token": "<你的强随机串>"` 后重启。）然后前端"管理"页填同款 token → 可看任意房间的：
- 叙事流（与玩家侧一致）
- 守密人笔记（KP 私有）
- 掷骰日志（所有玩家）
- 状态变动历史
- 玩家 LLM 调用记录（裁判/叙事两阶段、是否成功、ms、详细）
- 房间状态

> **未设置 dev_token 时监视完全不可用**（管理页所有查询按钮都会失败）。设置后记得重启后端。

**生产环境默认关闭**。要开就强随机，且日志不含 IP 明细（uvicorn `log_level=warning`）。

### 8.2 自定义模组

1. 在 `modules/<module_id>/` 建目录
2. 按 `docs/模组拆解说明.md` v1.1 写 `scenes.json` + `kp-notes.md` + `clues.md` + `handouts/`
3. 重启后端 → 总览页"选择模组"下拉自动出现

### 8.3 API 直接调用

```bash
# 1) 创建一个房间
curl -X POST http://localhost:18000/api/games \
  -H 'Content-Type: application/json' \
  -d '{"name":"试玩","module_id":"the-haunting"}'
# 响应里取 host_token + invite_token
# 2) 加入（带邀请 token）
curl -X POST http://localhost:18000/api/games/<key>/join \
  -H 'X-Join-Token: <invite_token>' \
  -H 'Content-Type: application/json' \
  -d '{"name":"测试员"}'
# 3) 建卡（带 player_token）
curl -X POST http://localhost:18000/api/games/<key>/character \
  -H 'X-Player-Token: <player_token>' \
  -H 'Content-Type: application/json' \
  -d @templates/character-sheet-template.json
```

完整 API 契约看 `docs/跑团Web平台-实施方案.md`。

### 8.4 性能基线

- 单房间 4 人同时玩：CPU <5%、内存 ~150MB（不含 LLM）
- 100 房间存档：SQLite 文件 ~50MB
- 并发 SSE 连接：每房间 50 客户端无压力（uvicorn 单 worker）
