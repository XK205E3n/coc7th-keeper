穿透 = 你的服务暴露在公网上。设个密码，朋友进房间要输密码。

```powershell

p = 'data/config.json'
d = json.load(open(p, encoding='utf-8'))
```

## 第 7 步 · 验证 E：异地 HTTPS 实战（最重要的一步）

这一步验证的是整个项目挂了三个里程碑的硬阻塞项：**异地 HTTPS 实战**。

1. 拿出手机，**关掉 Wi-Fi，用蜂窝流量**（确保不在同一个内网，测的才是真"异地"）
2. 浏览器访问第 6 步的公网地址：`https://你的地址.trycloudflare.com`
3. 完整玩一遍：
   - ✅ 页面能打开（不是 404 / 空白）
   - ✅ 地址栏有锁头（HTTPS 有效，无证书警告）
   - ✅ 建房 / 选预置卡建卡 —— **建一个填了「访问密码（可选）」的房间**
   - ✅ 掷骰，能看到结果
   - ✅ 推进一轮，AI 有回复（API Key 已就绪）
   - ✅ 房间里再拉一个人（或本机再开一个浏览器窗口），一边掷骰另一边**不刷新就能实时看到**
   - ✅ 另一设备加入时**必须输对房间密码**（这是本项目真正的密码关卡，见下方说明）

   > **为什么进首页不用输密码**：这是设计如此，不是 bug。`config.access_password` 是未实现的占位字段（服务端/前端均 0 处消费），本项目真正的密码关卡在**房间层** —— 创建时设「访问密码（可选）」，加入该房间必须输对。首页是静态资源，公开无敏感数据。安全边界：陌生人进不了你的房间（游戏号 + 邀请码 + 可选房间密码三重门槛）；仅剩的风险是陌生人可无门槛建垃圾房间消耗 LLM 额度，有每 IP 300 次/分钟限流兜底。若想要「进站先输密码」的全局门禁，属新需求，向 Kern 提即可。

有任何一步卡住：手机截图 + 电脑上跑 `Get-Content data\.run\backend.log -Tail 30`，一起发给 Kern。

## 附：故障速查

| 现象 | 原因 | 处置 |
|------|------|------|
| `NameError: name 'server' is not defined` | v1.0.3 已知 bug（PS 5.1 传参剥引号），**已修复** | `git pull` 后重跑 |
| 地址抓到了但手机打不开 | 国内访问 `trycloudflare.com` 慢/不通 | 网络问题。改用 cpolar：官网下载安装 → `data/config.json` 里 `"provider": "cpolar"` → 重跑 `-Tunnel`。顺带告诉 Kern cpolar 是否工作（它是未实测的 best-effort 实现） |
| `.\start-web.ps1` 提示"禁止运行脚本" | PowerShell 执行策略限制 | 在当前窗口跑一次：`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` 然后重试（只对当前窗口生效，安全） |
| 60s 超时「未抓到公网地址」 | 穿透进程启动慢或失败 | `Get-Content data\.run\tunnel.log -Tail 20` 和 `Get-Content data\.run\tunnel.log.err -Tail 20` 的输出发给 Kern |
| 改过 `server.port` 后后台模式报"未就绪" | 旧版硬编码 18000，**已修复**（读 config） | `git pull` |
