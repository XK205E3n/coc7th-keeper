## 1 · 任务清单（按 P 严重度）

### 阶段 A · 体验瑕疵修复（P2 · 建议做完再发版）

#### T-A1 `CharacterSheet.vue` 技能搜索覆盖度补全

- **状态**：待办
- **根因**：`CN_TO_EN` 表（`CharacterSheet.vue:118-132`）5 个 key 搜不到（实测脚本 `.tmp/verify_search2.py`）：
  - `化学 → chemistry`、`物理 → physics`、`生物 → biology` —— 模板里没有这 3 项独立技能（合并在 Science 下）
  - `藏匿 → hide` —— 没有 Hide 独立技能（合并在 Stealth 下）
  - `计算机 → computer` —— 模板技能名 `Computer Use`（是 `Elec Repair` 风格缩写，库里没有 `computer` 字符）
  - 缺口语词：「**开锁**」（表里有「锁匠」缺「开锁」）、「**心理学**」（表里有「心理」缺「心理学」）
- **改法**：
  - 把 5 个失效 key 改用 fallback：「化学/物理/生物」搜时找不到时退到 Science 组显示整组；「藏匿」搜时退到 Stealth；「计算机」改 key 为 `computer use` 配合 substr
  - 补口语词：`开锁: 'locksmith'`、`心理学: 'psychology'`（不是 `心理`）
- **验收**：用 `.tmp/verify_search2.py` 实测命中率为 100%；CDP 截图「搜『开锁』只剩 Locksmith」「搜『心理学』只剩 Psychology」

#### T-A2 `Characters.vue:70` UI 文案 bug

- **状态**：待办
- **根因**：`String(char.schema) ?? '（缺失）'` —— `String(undefined)` 返回 `"undefined"` 字面量（不是 null/undefined），`??` 永远不触发，用户看到「当前：undefined」
- **改法**：`${char.schema ?? '(缺失)'}`（先判 undefined 再 toString）
- **验收**：粘贴一个 `{"name":"x"}` 无 schema 的 JSON，错误提示显示「schema 必须为 "coc7-character/v1"（当前：(缺失)）」

#### T-A3 `EmptyState.vue` 改用 `#extra` 插槽

- **状态**：待办
- **根因**：subagent 自查发现 `n-empty` 实际有 `#extra` 插槽，下游 AI 用了 `#action` 不生效，把按钮挪到 `n-empty` 外渲染（hack）
- **改法**：用 `<n-empty><template #extra>...</template></n-empty>` 包住按钮，删 `.empty-action` 包装 div
- **附赠**：删 `title` prop 死代码
- **验收**：5 个空状态位置视觉无变化，DOM 层级更整洁

#### T-A4 阅读模态加 body 滚动锁定 + 无障碍属性

- **状态**：待办
- **根因**：`NarrationStream.vue:151-161` 模态打开未锁 body 滚动（移动端背景仍可滚）；缺 `aria-modal="true"`、打开/关闭时焦点管理
- **改法**：`onMounted` 锁 `document.body.style.overflow = 'hidden'`，`onUnmounted` 解锁；模态根加 `role="dialog" aria-modal="true"`；打开后 `nextTick(() => closeBtnRef.value?.focus())`，关闭后 `prevFocus.focus()`
- **验收**：移动端打开模态时背景不滚；键盘 Tab 焦点在模态内循环；屏幕阅读器宣告为对话框

#### T-A5 4 个 view 微观一致性

- **状态**：可选
- 内容：
  1. `CharacterSheet.vue` 初始不展开「其他」组（多数空）
  2. `Play.vue:55` `watch(gameKey)` 重置 `sideOpen = true`（跨房状态残留）
  3. `Admin.vue:22` 拆 `loadingList/loadingRoom/loadingResource` 避免 9 按钮同步 spinner
  4. `style.css` 落地 `--bp-mobile/--bp-tablet` 变量，各 view 引用
- **验收**：CDP 截图 4 个 view 三断点无明显差异（仅优化组织）
