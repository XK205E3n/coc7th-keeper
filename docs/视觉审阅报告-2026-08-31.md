## 二、按页视觉评估

### 2.1 Overview（总览）— `01-overview.png`

**亮点**
- 暗色主题（深紫底 `#121016` + 卡片 `#1a1720`）与品牌紫主色 `#a78bfa` 一致
- 「后端在线」状态指示器明显且语义清晰
- 中宫格布局对称、留白合理

**问题**
- **顶栏 active 状态错乱**：「总览」+「游玩」同时高亮（其他页同样症状），Vue Router 的 `meta.activeMenu` 没正确映射或 Naive UI `n-menu` 的 `value` 未与 `route.path` 联动
- 「最近游戏」空状态图标（文档+大 X）语义像「出错」而非「空」

### 2.2 Play（游玩）— `02-play.png` ⭐ 核心

**亮点**
- 场景栏 + 叙事流 + 行动输入三段式逻辑清晰
- 每轮叙事独立卡片，骰卡嵌入合理，成功/失败徽章颜色（红/绿）易识别
- 玩家列表展示「审判官 / 房主」「艾伦 / 调查员」角色位清晰
- 聊天卡片整合掷骰（`1d100=74 [74]`）直观

**问题**
- **顶栏 active 状态错乱**：「总览」+「游玩」同时高亮（其他页同样症状）。**根因**：`App.vue:118-122` 用 `.router-link-active`，而 Vue Router 4 默认行为是「`to` 是当前路径祖先时也激活」；`to: '/'` 永远命中 → "总览"始终高亮。修复需改 `App.vue:51-58` 或加 `exact`/`exact-active-class`。
- **聊天流已正确隔离**到右栏 `ChatPanel.vue`（`Play.vue:237`、`NarrationStream.vue` 无 chat 兜底靠 `v-else` JSON 显示、`game.ts:295-299` SSE `chat` 进 `chats` 数组不进 `messages`）。早先误判"聊天插入叙事流"撤回 —— 视觉上看似在第 3 轮叙事段中的"我说："实为 AI 叙事引用句，不是聊天卡。
- **聊天卡片在右栏底部**与"行动"按钮邻接，输入框 + 发送/掷骰双按钮紧凑，可读但偏挤。
- **「我的角色」空白态过于简陋**：未建卡时只有一根图标+「暂无」文字，缺少「去建卡」引导按钮。
- **行动按钮（右下「提交行动」）位置合理**，但 textarea 没显式字数提示（长文本会被截断）。
- **隐私敏感信息无视觉区分**：私密感知 vs 公开叙事的边界仅靠右栏分栏，没色彩/徽章强化。
- **🚨 骰卡纯白底，暗色 UI 里最刺眼的一块**（E3n 反馈）：`DiceCard.vue:132` `background: var(--card-color, #fff)` —— `--card-color` 全仓从未定义，兜底 `#fff` 必然生效。每出现一次检定就撞一块白板。连带问题：`.ok-text` `#18a058` / `.bad-text` `#d03050` 是 Naive UI **亮色主题**的红绿，在暗底上对比度不足。已列为任务书 **T-B4**（建议改深蓝 `#17233c` + 蓝调边框 `#35507f`，复用 `style.css` 里已有的 `--success-color` / `--error-color`）。

### 2.3 Characters（角色）— `03-characters.png`

**亮点**
- 「已建卡」绿色状态横幅明确
- 派生属性（HP/MP/SAN/DB/MOV）一行 5 列节省垂直空间
- 技能列表按数值降序排列便于速读

**问题**
- **42 项技能长列表无搜索/筛选/分组**：玩家想找「急救」必须滚动到底
- **属性九宫格上下行布局不均**：上半 3×3 = 9 属性，下半 5 列派生。视觉上像两张不同表格拼贴，缺少统一栅格感
- **没有「打印/导出」入口**：COC 玩家常需纸质卡

### 2.4 Content（内容）— `04-content.png`

**亮点**

**问题**

- **折叠列表无摘要预览**：需展开才知道内容，影响挑选

### 2.5 Admin（开发者监视）— `05-admin.png`

**亮点**

- **缺少 dev_token 设置引导**：管理员拿到 data/config.json 路径说明后没有 UI 内的「点这里复制路径」或「查看生成示例」

## 四、按严重度排序的视觉缺陷清单

### P0 · 阻塞体验

1. **移动端完全不可用**（`06-play-mobile.png`）—— Play 页是产品核心，移动端崩盘意味着无法在手机/小屏边玩边看。影响所有外出场景玩家。**根因**：`Play.vue:269-275` `.play-side { width: 330px; flex-shrink: 0 }` 在 390px 视口下吃光主区。
2. **顶栏 active 双高亮 bug** —— 全站 5 页都可见，第一眼就显粗糙，破坏品牌可信度。**根因**：`App.vue:118` 用默认 `.router-link-active` + `to:'/'` 永远命中祖先匹配。

### P1 · 明显问题

3. **空状态视觉过于简陋**（"我的角色暂无"/"最近游戏"空图标）—— 没有引导动作。
4. **Skills 长列表无搜索**（`03-characters.png`）—— 42 项手动滚动不可接受。
5. **Admin 未鉴权态按钮可点** —— 误导 + 多次 401。
6. ✅ **骰卡白底**（2026-08-31 已修）：`DiceCard.vue` 改深蓝 `#17233c` + 蓝边框 `#35507f` + 蓝调标签 `#93a9cc`；成功/失败色改用 `style.css` 暗色 token。对比度 12.5:1。截图 `.tmp/shots/09-dice-darkblue.png`。
7. **Play 信息密度过高**，缺「阅读模式」—— 8+ 轮后叙事卡视觉争抢。

### P2 · 优化项

8. ChatPanel 掷骰按钮缺少 🎲 视觉强调。
9. Content 页面信息量低，下方大空白。
10. 属性九宫格上下行不均。
11. 隐私/公开叙事视觉边界弱。
12. 行动 textarea 缺字数/截断提示。
