# 单人测试一键开团手册

> 适用：在本机用根目录的「一键开启.bat / 一键关闭.bat」完成**前端 + 后端 + 内网穿透**全流程，
> 全程只需**双击两个 .bat 文件 + 用浏览器操作**，不需要编辑任何文件。
> 编写：2026-09-04（M8R8）。遇到问题直接翻到文末「故障排查」。

---

## 开始前的状态说明

本仓库当前已具备全部前置条件（虚拟环境 `.venv`、前端依赖、`cloudflared` 穿透工具、模组库），**不需要任何安装或配置，直接从第一步开始**。唯一可能用到的密码设置已内置在开启流程里（见第二步，直接回车也能跳过）。

---

## 第一步 · 一键开启

1. 打开文件管理器进入本仓库根目录（就是 `start-web.ps1`、`一键开启.bat` 所在的文件夹）。
2. **双击「一键开启.bat」**。会弹出一个黑色命令行窗口，依次出现：
   - **设置进站密码**（仅当之前没设过密码时才出现）：
     ```
     设置进站密码（公网进站需输入；直接回车 = 不设密码）：
     ```
     输入一个你自己定的密码并回车（**朋友进站时要用**）；不想设密码就直接回车跳过。
   - `[1/2] 启动后端与前端...建立内网穿透...`——这一步约需 **10～30 秒**（首次或前端有更新时会多等一会儿，窗口会显示构建进度）。
   - **网址汇总块**——长这样：
     ```
     ============================================================
      🎲 跑团平台网址汇总
     ------------------------------------------------------------
      后端状态　：运行中
      本机游玩　： http://localhost:18000
      公网分享　： https://xxxx-yyyy-zzzz.trycloudflare.com
      隧道类型　： cloudflared
      进站密码　： 已设置（进站需输入密码）
     ------------------------------------------------------------
      关闭方式　：双击根目录「一键关闭.bat」，
      　　　　　　或命令行执行  .\stop-web.ps1
     ============================================================
     ```
3. **这个黑色窗口不用管它**——可以直接最小化，甚至直接关掉也不影响服务（真正干活的进程在后台）。它只是用来给你看网址的。

> ⚠️ 如果窗口里出现「检测到后端已在运行。按 R = 重启到最新代码；按 E = 直接沿用当前服务」：
> - **不确定就按 R**——会先关掉旧服务再以最新代码重新开启（推荐，每次开团前按 R 保证跑的是最新版本）；
> - 按 E 则沿用已在跑的服务（适合你确定它就是刚开过的场景）。

## 第二步 · 认准两个网址

| 网址 | 谁用 | 说明 |
|------|------|------|
| **本机游玩** `http://localhost:18000` | 你自己（这台电脑） | 永远可用，与穿透无关 |
| **公网分享** `https://xxxx.trycloudflare.com` | 朋友 / 你的手机 | 从窗口的网址汇总块里复制；**每次重新开启都可能变化**，以本次显示的为准 |

- 进站密码：开启时设置的那个。浏览器打开网址后先出现密码门，输入即可（本机 localhost 同样要输入）。
- 忘记密码了？看文末「故障排查」第 3 条。

## 第三步 · 开团（浏览器操作）

1. **你（房主）**：浏览器打开**本机游玩**地址（或公网地址，一样）→ 输进站密码 → 总览页。
2. 左侧「**创建冒险**」：填冒险名称（如"单人测试团"），可选一个模组，玩家名填你的名字 → 点「**创建**」。创建成功会提示"邀请链接已复制"，且下方「最近游戏」出现这一团。
3. **手机或朋友加入**：朋友用浏览器打开**公网分享**网址 → 输进站密码 → 把你复制的**邀请链接**发给他（微信直接发就行），他打开后填玩家名 →「加入」。你自己手机测试也一样：手机浏览器开公网地址。
4. 建角色卡：进房后右侧「我的角色」→「去建卡」→ 选预制角色 / AI 草稿 / 手动填写 / 粘贴 JSON 任一方式。
5. **玩**：右栏「行动」卡输入你这轮做什么 →「提交行动」→ 全员提交后出现绿色「**推进回合**」（任何人可点；有人没提交时房主看到的是黄色「强制推进（将跳过 N 人）」）→ AI 结算后叙事出现在左侧。
6. 左下「聊天」可以打字交流，也能输入骰子表达式（如 `1d100`）点「掷骰」。

## 第四步 · 一键关闭

测完之后任选一种：

- **双击根目录「一键关闭.bat」**——会显示「已关闭 N 个进程（后端 / 穿透 / Vite）」；
- 或在命令行（PowerShell）里执行 `.\stop-web.ps1`。

关闭后：后台进程全部结束，日志保留在 `data\.run\`，房间数据保留在 `data\games\`（下次开启还能继续）。重复关闭是安全的（会提示"无运行中进程"）。

## 故障排查

| 现象 | 处理 |
|------|------|
| 公网分享显示「（未取得）」 | 穿透没成功：看黑色窗口上方 `start-web.ps1` 的红字报错。常见原因：网络不通、cloudflared 掉线。先双击「一键关闭.bat」再重新双击「一键开启.bat」重试一次；只在本机玩可无视，直接用本地地址 |
| 提示「检测到后端已在运行」 | 按上面第一步的 ⚠️ 说明：拿不准就按 R 重启到最新代码 |
| 忘记进站密码 | 在仓库根目录命令行执行（整行复制粘贴即可，把"新密码"换成你想要的）：`.venv\Scripts\python.exe tools\config_cli.py set-access-password 新密码` |
| 端口被占用 / 想换端口 | 打开 `data\config.json` 把 `server.port` 改成别的数字（如 18001）——这是全手册唯一可能要动手改文件的地方，改完重新一键开启；拿不准就把这行话发给 AI 帮你改 |
| 朋友的公网地址打不开了 | 公网地址**每次重新开启都会变**：重新看一眼本次网址汇总块里的「公网分享」，把新地址发给他 |
| 关闭后朋友页面显示断线 | 正常，服务已停。下次开启后让他刷新即可 |
| 双击 bat 窗口一闪而过 | 说明有报错一闪而过：改为在地址栏输入 `cmd` 回车打开命令行，手动输入 `一键开启.bat` 回车运行，就能看清报错；或直接截图发给 AI |
| 「错误：未找到虚拟环境 .venv」 | 仓库没装好。在根目录命令行依次执行：`python -m venv .venv` 和 `.venv\Scripts\python -m pip install -r requirements.txt` |

## 附 · 命令行等价方式（可选，不用 bat 时）

```powershell
cd 仓库根目录
.\start-web.ps1 -Tunnel    # 一键开启的命令行版（同样的全流程）
.\stop-web.ps1             # 一键关闭的命令行版
```

其他模式（`-Dev` 开发热重载、`-Daemon` 仅后台后端、`-Provider mock` 演练穿透）见 `docs\操作指引.md`。
