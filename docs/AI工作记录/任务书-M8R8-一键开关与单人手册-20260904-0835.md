## 0. 现状与复用

穿透/启停的全套底层能力已在 M8R4 交付并经 E3n 真穿透实测：`start-web.ps1 -Tunnel`（前端 Ensure-Dist + 后台后端 + 四 provider 穿透 + URL 抓取回写 `share_url`）、`stop-web.ps1`（树杀 + 幂等）、`tools/config_cli.py`。**本轮不重写这些逻辑，只加薄壳与收尾件**：

1. `一键开启.bat`（根目录，双击即用）：
   - 预检 `.venv` 存在；**已在运行则直接打印网址并退出（幂等，防重复拉起）**；
   - 进站密码未设置时交互式补设（`config_cli.py ensure-access-password`，直接回车可跳过）；
   - 调 `start-web.ps1 -Tunnel`（复用已验证逻辑，不复制粘贴）；
   - 收尾由 `tools/print_urls.py` 在**命令行最下方**打印网址汇总块（本地 + 公网 + 密码状态 + 关闭方式），`pause` 保持窗口可见。
2. `一键关闭.bat`（根目录）：调 `stop-web.ps1` + 结果提示 + `pause`。命令行路径维持 `.\stop-web.ps1` 不变。
3. `tools/config_cli.py` 增 `set-access-password <pwd>` / `ensure-access-password`（交互式，密码走 input 不进命令行历史）。
4. `tools/print_urls.py`（新）：读 config 打印网址块；`check` 模式探测后端健康（供 bat 幂等分支）。
5. `docs/单人测试一键开团手册-20260904.md`（玩家文档，docs 根目录）：0 前置一次性检查 → 双击开启 → 读网址 → 建房游玩 → 关闭；含故障排查表；**全程只需双击与浏览器，不要求编辑任何文件**。
6. `docs/操作指引.md` §1.2 加一行指针；CHANGELOG 补记十六。
