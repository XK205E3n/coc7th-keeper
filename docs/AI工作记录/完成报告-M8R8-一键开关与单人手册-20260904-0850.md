## 1. 「一键开启.bat」行为链

```
双击 → 预检 .venv（缺失给出一次性安装指引并 pause）
     → print_urls.py check：后端未跑 → 直接进入开启流程
                            后端已跑 → 打印当前网址块 + choice：
                                       R = stop-web.ps1 后重启到最新代码（推荐默认认知）
                                       E = 沿用当前服务（pause 退出）
     → config_cli.py ensure-access-password：密码已设 → 打印"跳过"
                                            未设 → 交互输入（回车可跳过）
     → [1/2] start-web.ps1 -Tunnel（前端 Ensure-Dist + 后台后端 + 穿透 + share_url 回写）
     → [2/2] print_urls.py：命令行最下方打印网址汇总块
     → pause（窗口保持，URL 始终可见；窗口可最小化/直接关闭，服务在后台不受影响）
```

**幂等分支的动机**：验证期间发现实机 18000 端口有 E3n 早前遗留的后端进程——若盲目"已在运行就跳过"，双击开启会沿用**旧代码服务**而不自知。choice 分支把这个选择权交给用户，并在手册中建议"拿不准就按 R"。
