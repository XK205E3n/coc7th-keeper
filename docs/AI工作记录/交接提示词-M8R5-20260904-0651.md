## 六、工程约定（必须照做）

**验收门禁**（改完必跑）
```powershell
.venv\Scripts\python.exe -m pytest --basetemp=".tmp/pt-$(date +%s)" -q   # 基线 96 passed
cd frontend && npm run build                                              # vue-tsc 0 错
.venv\Scripts\python.exe .tmp/linkcheck.py                                # 0 断链
```
- **basetemp 必须全新目录**：固定 `--basetemp=.tmp/pytest` 会因沙箱拦 `shutil.rmtree` 导致 tmp_path 夹具全挂（91 全 ERROR，不是回归）
- **用 `.venv/Scripts/python`，不要重建 venv**：重建会稳定掉 5 个 live-SSE 测试（86/5），那是环境差异不是回归

**PowerShell 脚本编写**（本轮踩过三个坑）
- **禁止** `python -c "<内嵌代码>"`：PS 5.1 传参会剥内嵌双引号 → `NameError: name 'server' is not defined`。一律走独立脚本文件（现成的：`tools/config_cli.py`，支持 `get` / `set-share-url` / `set-dev-token`）
- **禁止**用 `$pid` 作变量名（PS 自动变量），用 `$procId`
- `Start-Process` 的 `-RedirectStandardOutput` 与 `-RedirectStandardError` **不能指向同一文件**（会抛 `InvalidOperationException: ...are same`）
- 脚本文件必须 **UTF-8 带 BOM**，否则中文 locale（GBK 936）下 PS 5.1 会误读注释报伪语法错

**命名规则**（`docs/AI工作记录/README.md`）
```
<类型>-<序列名>-<简要>-<YYYYMMDD>-<HHMM>.md
任务书-M8R5-回合流程与可观测性-20260903-2210.md
```
类型：任务书 / 完成报告 / 审阅报告 / 影响面评估 / 验证清单 / 交接提示词 / 复检 / 规划对话
序列名：`M8R1`…（任务书与其完成报告共用同一序列名）；日期时间取**北京时间 UTC+8**，精确到分钟
硬约束：禁「下一步工作 / 下一步任务」字样；禁只写日期不写时间

## 七、环境坑（本机沙箱，会浪费你时间）

| 坑 | 表现与处理 |
|----|-----------|
| **`origin/master` 引用丢失** | `git status` 显示 `[gone]`、`git rev-parse origin/master` 报 `Needed a single revision`。push 后仍会丢 → 用 Python 直写 `.git/refs/remotes/origin/master` 恢复。**每次 push 后必查** |
| **packed-refs CRLF** | 变成 CRLF 后 git 2.55 不剥 `\r`，引用名尾部带 CR → 刷 `ignoring ref with broken name ...?`。Python 把 CRLF 全换 LF 即恢复 |
| **PowerShell 工具禁拉起后台进程** | `Start-Process` 及等效外部程序被安全策略拦截，输出被吞且不报错 → 启停类 `.ps1` **无法端到端实跑**。替代：① 语法校验用 `Parser.ParseFile`；② 逻辑用 Bash + Python 等价编排；③ 运行时行为差异靠文档/搜索取证。**凡此类改动必须在完成报告里标注哪些验证是等价替代** |
| **Bash 工具禁 `powershell` 命令** | 会报 "Invoking PowerShell from Bash bypasses security"；Bash 可正常跑 python/node/git/npm |
| **PowerShell 工具输出不回流** | `Write-Host`/`Write-Output` 看不到，需 `Out-File` 落盘再用 Read 读 |
| **gh CLI 凭据会丢** | `gh auth status` 报未登录，但 git push 仍成功。修复：`printf 'protocol=https\nhost=github.com\n\n' \| git credential fill \| grep '^password=' \| sed 's/^password=//' \| gh auth login --with-token`（token 全程走管道，不落输出） |
