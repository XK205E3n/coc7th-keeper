# AI 工作记录（内部过程档案）

> **本目录不是玩家文档。** 这里存放 AI 协作开发过程中的工作产物：审阅报告、复检记录、任务书、完成报告、影响面评估。
> `docs/` 根目录只保留**给玩家阅读**或**给外部 AI 参考**的文档（计划书 / 实施方案 / 操作指引 / 模组拆解说明 / 角色卡模板 / 规则依据 / 部署）。

## 归档与命名规则（2026-09-02 起强制执行）

### 归档位置

| 产物 | 位置 |
|------|------|
| 任务书 / 完成报告 / 审阅报告 / 复检 / 影响面评估 / 规划对话 | **本目录 `docs/AI工作记录/`** |
| 计划书 / 实施方案 / 操作指引 / 模组拆解说明 / 角色卡模板 / 规则依据 / 部署 | `docs/` 根目录 |
| 历史事实 | 根 `CHANGELOG.md`（唯一） |

**任务书类文件一律不得出现在 `docs/` 根目录。**

### 文件名格式

```
<类型>-<序列名>-<简要>-<YYYYMMDD>-<HHMM>.md
```

| 段 | 取值 | 说明 |
|----|------|------|
| 类型 | `任务书` / `完成报告` / `审阅报告` / `影响面评估` / `验证清单` / `交接提示词` / `复检` / `规划对话` | 产物类型 |
| 序列名 | `M8R1`、`M8R2`… | 里程碑 + 该里程碑下第几轮。**任务书与它对应的完成报告共用同一序列名** |
| 简要 | 4~10 字 | 本轮主题，如 `P3收尾`、`ComputerUse与建卡校验` |
| 日期时间 | `20260902-1412` | **北京时间（UTC+8）**，精确到分钟 |

### 硬约束

1. **禁止**出现「下一步工作」「下一步任务」等字样 —— 语义随轮次失效，隔一天看就是错的。
2. **禁止**只写日期不写时间 —— 同一天内可能开出多份任务书，靠 `HHMM` 区分。
3. 任务书与完成报告**必须成对同序列名**，便于按轮次检索。

## 交接约定

交给下游工作 AI 时，通常需要一并提供：

1. 本目录中的**最新任务书**（当前为 `任务书-M8R5-回合流程与可观测性-20260903-2210.md`）
2. 相关的**审阅报告**（作为问题依据）
3. 仓库根目录的 [`CHANGELOG.md`](../../CHANGELOG.md)（唯一历史事实源）与 [`docs/操作指引.md`](../操作指引.md)（现状手册）

任务书执行完成后，**完成报告**同样归档到本目录（按同一序列名命名），并在 `CHANGELOG.md` 追加条目。
