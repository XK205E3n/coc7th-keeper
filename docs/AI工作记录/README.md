## 交接约定

交给下游工作 AI 时，通常需要一并提供：

1. 本目录中的**最新任务书**（当前为 `下一步工作-任务书-2026-09-02.md`）
2. 相关的**审阅报告**（作为问题依据）
3. 仓库根目录的 [`CHANGELOG.md`](../../CHANGELOG.md)（唯一历史事实源）与 [`docs/操作指引.md`](../操作指引.md)（现状手册）

任务书执行完成后，**完成报告**同样归档到本目录，并在 `CHANGELOG.md` 追加条目。
