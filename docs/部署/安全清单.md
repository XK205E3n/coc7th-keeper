# 安全清单（M6.5）· 上线前逐项核对

> 目的：让"对外开团"不裸奔。每项标注**落实位置**与**检查方法**。

## 1. 访问密码（哈希存储）✅ 已实现
- 每局可选访问密码，`auth.hash_password` 盐化 sha256 后存 `games.password_hash`；`POST /join` 校验。
- 检查：`data/games/<key>.db` 里 `password_hash` 为 `salt$hex` 形态；公共视图不含该字段（测试覆盖）。

## 2. 邀请凭证不泄露 ✅ 已实现
- `invite_token` 只出现在创建/轮换响应与加入请求校验中；**公共视图、玩家视图、dev 只读接口均不含**（测试覆盖）。
- 轮换即失效：房主面板"刷新"后旧链接立即作废。

## 3. `secrets.json` 文件权限 🔒 部署时操作
- 位置：`data/secrets.json`（`api_key`）。`.gitignore` 已排除 `data/`，不会被提交。
- Windows：右键文件 → 属性 → 安全 → 仅保留当前用户与 SYSTEM（默认继承即可，重点**别把 data 目录共享**）。
- Linux：`chmod 600 data/secrets.json && chown 启动用户 data -R`。
- 检查：`git status` 不应出现 `data/` 任何文件。

## 4. `data/` 不公开 ✅ 代码层面已隔离
- SQLite 存档在 `data/games/`，后端**没有静态挂载 data/**（只挂 `frontend/dist`）；前端无任何读 data 的接口。
- 反代/对象存储不要额外把仓库根目录发布出去（尤其 `data/`、`.venv/`、`.git/`）。
- Nginx 兜底（若根目录被发布）：`location ~ /\.git { deny all; }`、`location ^~ /data/ { deny all; }`。

## 5. 访问限流 ✅ 已实现（可配）
- 中间件：每 IP 滑动窗口，`data/config.json` `rate_limit` 可调（默认 300/分钟、单秒 20），超限回 429。
- 仅作用于 `/api`；静态资源不限。
- 检查：`python -c "..."` 连续快速请求 300+ 次应见 429（测试 `test_rate_limit_middleware_429` 覆盖）。
- 注意：多实例/跨进程部署时内存限流不共享，需换 Redis（单实例开团够用）。

## 6. 日志脱敏 ✅ 已实现 + 文档
- 后端 `log_level=warning`：uvicorn 访问日志关闭，**不落 IP 明细**。
- 掷骰审计 `dice.log`（`dice_log` 表）的 `--why`/reason 是玩家可见内容——守密人内部观察只准进 kp-notes，禁止写进 reason（提示词 §2 硬约束 + 隐私自检清单）。
- LLM 调用记录只存 `stage/ok/ms/detail(字符数)`，不含提示词原文。
- 检查：`server/main.py` 默认 `log_level="warning"`；运行日志不应出现 `/api` 逐请求行。

## 7. `dev_token` 管理 ✅ 默认关闭
- 未配置 `data/config.json` 的 `dev_token` 时，`/api/dev/*` 一律 503；配置后须 `X-Dev-Token` 匹配（401 拒绝）。
- **对外部署务必设置高强度随机值**，且不写入任何公开文档；定期轮换。
- 监视接口只读（测试断言调用后游戏状态不变）。

## 8. 其它上线建议
- Docker：`data` 用卷挂载，避免写进镜像层（Dockerfile 已 `VOLUME /app/data`）。
- 云服务器：仅放行反代端口（80/443）+ 可选 18000 内网访问；SSH 用密钥。
- 模型 API Key：`secrets.json` 权限同 §3；换模型端点即换 `config.json`。
- 定期备份：`data/games/*.db`（WAL 模式下停服后拷贝最稳）。
